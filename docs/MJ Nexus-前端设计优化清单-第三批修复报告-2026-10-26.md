## 一、修复明细

### P1-17 模型配置无扶手
- **根因**：`ModelsTab.tsx` 的添加服务商（`addProvider`）三段输入框仅有 placeholder，无 label、无必填标记、无「去哪拿 Key」指引；首启最关键一步用户对着三个空框不知如何开始，卡在这里等于产品不可用。
- **修复**：
  - `settings/shared.tsx` 的 `Input` 原语扩展可选 `label` / `hint`（均为 `ReactNode`，向后兼容既有调用——其他设置页仅传 `placeholder/value/onChange/type` 不受影响）。
  - `ModelsTab.tsx` 为「服务名称 / 接口地址 / API Key」三段补 label + 必填红星标；API Key 的 placeholder 由硬编码 "API Key" 改为 i18n 键，并加 hint 指引「在服务商控制台（如 platform.deepseek.com）的 API Keys 页面创建；本栏以密码形式保存，不会明文显示在界面」。
- **新增键**：`settings.providerNameLabel` / `providerUrlLabel` / `providerApiKeyLabel` / `providerApiKeyPlaceholder` / `providerApiKeyHint`（zh-CN + en-US）。

### P2-9 向导目录只给 6 条
- **根因**：`Onboarding.jsx` 员工 / 技能 / 连接器三步硬切 `slice(0, 6)`，无总数、无「查看全部」；容器本有 `overflow-y-auto`，但因只渲染 6 条形同虚设，用户以为目录只有 6 个。
- **修复**：新增 `showAllEmp` / `showAllSkills` / `showAllConn` 三个开关（默认 false）；三步 `slice` 改为 `showAll ? length : 6`；当该目录 > 6 条时，网格下方显示「查看全部 N 个」/「收起」切换按钮（展开后容器滚动显示完整列表）。
  - `renderer/src/components/Onboarding.jsx`（三步各加片段包裹 `<>...</>` 以容纳按钮节点）。
- **新增键**：`onboarding.viewAllCount` / `showLess`（zh-CN + en-US）。

### P2-10 项目创建按钮灰但无红字
- **根因**：`ProjectCreateModal.tsx` 打开即 `invalid`（`name` / `objective` 为空），但 `errorFor` 仅在该字段 touched 或有内容时才显红，未填字段不显示红字；footer 仅一句「请先补全必填项」，用户看不到哪几处卡住，只看见灰色按钮。
- **修复**（尊重原代码注释「打开即满屏红字不易读」的设计，用扶手替代全红）：
  - `name` / `objective`（及选「使用现有团队」时的 `teamId`）label 加必填红星标，常驻提示哪些是必填。
  - `Field.label` 类型由 `string` 放宽为 `ReactNode`，以支持内联星标。
  - footer 提示改为动态数量「还有 N 处待修正」（N = 当前 blocking 错误数），使灰色按钮的原因可被定位。
- **新增键**：`projectSpace.requiredHintCount`（zh-CN + en-US）。
