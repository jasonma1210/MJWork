## 建议的闭环顺序

1. **T-03 / T-04 / T-05**（门禁补强）—— 先补门禁，再修 T-01 / T-02；否则修完也没有回归保护。
2. **T-01**（topK）—— 影响面小、修法清晰，且是本轮唯一有直接行为证据的正确性缺陷。
3. **T-02**（SSRF 旁路）—— 安全类，改动集中在 `assertHttpUrl`，但需要补「重定向复检」与「本机端口例外」的产品决策（本地开发场景常需访问 `localhost`）。
4. **T-06**（写入队列 flush）—— 改 `localData.js` 的 flush 触发点，低风险。
5. **T-07 / T-08 / T-09** —— 记忆链路的规格收敛（要么接上、要么删掉），建议一并做「记忆链路端到端断言」。
6. **T-10** —— 写进核查文档即可。
