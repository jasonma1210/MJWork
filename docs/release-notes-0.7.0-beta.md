# MJCode 0.7.0-beta

本次更新包含两项主要内容：**MJ Bot（团队编制）正式成型**，以及**记忆系统扩展到团队层**。

此前「派一个任务给几个 Agent 一起干」已经可以运行，但团队身份、成员记忆、超支处置仍是空白。本次更新补全了这三项能力：团队有了编制（角色 / 模型 / 预算 / 归属），记忆有了团队层（共享 + 成员私有 + 提名晋升），成本有了项目级账本（跨天滑动配额 + 暂停恢复 + 单成员熔断）。

> 完整改动：`v0.6.1-beta..v0.7.0-beta`。运行时升级至 Electron 45（Chromium 156 / Node 24.22）。

## MJ Bot：从「能派活」到「一支可管理的团队」

### 团队编制（人）

「+ → 团队编制」管理你的数字员工编队：

- **成员上限 8 → 20**，统筹（Lead）全局唯一；招募 / 自定义成员在弹窗内以标签就地累积，不用关窗重开；
- **AI 自动创建员工**：描述一句「我要一个擅长写 Java 后端的员工」，自动生成名称、系统提示与工具集草稿，回填后可手动改；
- **工作目录可选**：全局团队不绑项目，任意对话都能派活；团队卡片可选本机最近项目作为默认目录；
- **预算可编辑**：每支团队可配 token 预算（1000 ~ 2000000）与轮次上限。

界面侧修掉了五个真机问题：新建团队空白名 / 空白描述**必填并就地在弹窗内报错**（此前错误提示被弹窗遮住，表现为「点创建没反应」）；「工作目录（可选）」从自由文本改为**下拉选择本机项目**；归档入口下线（后端语义保留）。

### 派活入口（事）

选中团队后，输入区上方出现一条**常驻派活目标条**——团队名、成员数、预算档一目了然，✕ 一键取消；发送按钮切换为派活语义。此前只有一个 10rem 宽的小徽标，成员一多就被截断。排队中的消息会在上一轮结束后按当前选择自动分流到派活或普通发送，不会再「发错通道」。

Worker 侧：有成员归属的子任务现在会在系统提示里带上了「你是「成员名」」的身份段——同一个任务，团队成员知道自己是谁。

任务面板的每条军团 run 现在带徽标，「这是团队 run 还是单会话 run」不再靠猜。

### 团队执行：真机问题修复

以下问题均在真机运行中复现并修复：

- **预算不再「人均配额」**：组预算是成本信封，不是把总额除以人头。此前 4 名成员的团队每人都被自己的份额掐断，全员失败；现在单任务按组剩余额度派发，超额只告警不硬停，界面上超额会显示实际倍数（`4.2×`）并注明「Token 为软上限，任务继续执行」；
- **不再「假完成」**：任一任务失败或被跳过，组状态如实落 failed 并写明原因——此前 3 个任务没跑、组仍显示 done，用户拿到的是错的答案；
- **macOS 27 沙箱兼容**：新版 macOS 上 shell / python 一启动就崩溃的问题已修（写限制档 + 自动降侧），工作区外写入仍被拒绝；
- **上下文耗尽不再被误判为完成**：模型窗口打满时的空产出会明确标记「任务未完全完成」；
- **成员技能按需读取**：成员挂载的技能默认只注入摘要（此前全量注入，一个「报数」子任务 2 轮烧 69k tokens）；
- **工具连续失败 6 次快速收尾**，不再空转 20 轮；
- **依赖级联**：前置任务失败时，依赖它的任务自动置 skipped，不再永久 pending 让组悬挂转圈；
- **团队结果落页**：最新一次 run 始终展开，卡片顶部有「最终交付」区——修掉了「5/5 完成却看不到任何结论」和摘要显示 `[object Object]` 两个问题。

### 可观测性：Debug 日志一键导出

团队页头部新增「调试日志」：默认开启，全链路记录（派活 → 拆解 → 认领 → 引擎 → 落库 → 协同工具），密钥自动脱敏；一键导出 ZIP（含版本 / 平台元信息），复现一次即可交出完整证据包，不必再靠截图描述。

## 记忆系统：新增团队层（四层记忆）

记忆从 `session / project / global` 三层扩展为 **`session / team / project / global` 四层**：

- **团队共享层**：团队成员的共识与约定，全团队可见；
- **成员私有层**：单个成员的私有记忆，跨团队严格隔离；
- **半衰期**：团队层 30 天（与项目层同档），评分 / 衰减走同一套规则；
- **容量**：每团队上限 200 条，纳入统一的淘汰口径；
- **提名制晋升**：命中 ≥3 次的团队记忆进入「待晋升候选」，在记忆面板一键确认后才提升为项目记忆——团队专有约定默认不自动污染跨项目上下文；
- 记忆面板新增 team 域筛选与「待晋升候选」区块。

## 项目空间与工件：跨天迭代的底座

参照 DS Bot 插件的多 Bot 长期协同能力（agent-core 零改动，全部包在宿主侧）：

- **项目空间**：一个项目 = 一个稳定身份（`prj_...`）+ 一个会话 + 可选一支团队。创建时七步初始化（项目 → 工件 → 配额桶 → 会话 → 团队 → 首条消息 → 快照），任一步失败自动回滚，不留半成品；目标锁定后跨天续跑无需重述需求；
- **工件库**：文档 / 方案 / 计划的正文进库不进消息链，模型通过四个工具协作——`artifact_index`（看索引）、`artifact_get_section`（按章节读，≤8000 字符/次）、`artifact_patch_section`（带版本号乐观锁修改，冲突返回 diff 不静默覆盖）、`artifact_get_diff`（看版本差异）。侧面板可随时查看文档 / 版本 / 待办；
- **滑动配额**：每个项目一个跨天的成本账本（档位 1M/2h、3M/6h、10M/24h 或自定义）。额度不足时新任务转「已暂停」（不是失败——任务、文档、消息全部保留），后台自动老化，恢复后小批量续跑，版本连续不丢；
- **单成员熔断**：某个成员 10 分钟内烧掉桶量 30% 且超 100k 即被熔断（只锁它自己，同队其他人照常），10 分钟后单探针恢复。

冷启动时只装配四项上下文：固定目标 + 上次迭代摘要 + 未完成待办 + 工件索引——**工件正文永不进装配**，模型需要内容时按需读取。

## 升级须知

- **macOS 12 及更早无法运行本版**（Electron 45 要求 macOS 13+）。已在用旧版的用户，自动更新不会跨大版本推送，请手动下载；
- **首次启动会触发钥匙串授权弹窗**（加密存储迁移），请输入登录密码并选择「始终允许」；授权期间可能出现一次白屏，重启即恢复；
- 数据库迁移（v14）在首次启动自动执行，新增项目空间 / 工件 / 配额表，既有数据不动；
- 本版为 beta 通道：`v0.7.0-beta`，自动更新渠道为 beta；
- 团队 / 记忆 / 工件能力均向后兼容：0.6.x 创建的团队与记忆在升级后继续可用。
